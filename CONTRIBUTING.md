# Contributing

Thanks for your interest. Hamster is run by one person, so for now:

- **Issues are welcome.** Bugs, ideas, and requests for AI tools to support.
- **Pull requests are not accepted yet.** Please open an issue instead. This
  may change later.
- Forks are welcome under the MIT license for the code. The hamster artwork is
  not redistributable; see [ASSETS-LICENSE.md](ASSETS-LICENSE.md).
