# Security

Hamster adds hooks to your AI coding tools' config files and can replace itself
when you click the update item, so security reports matter a lot.

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/fbwndrud/hamster/security/advisories/new),
not as a public issue.

Updates are verified before install. The app accepts an update only when its
manifest carries a valid Ed25519 signature from the release key embedded in the
app, and the downloaded file matches the signed SHA-256 and size.

보안 문제는 공개 이슈 대신 위 링크로 비공개로 알려 주세요.
